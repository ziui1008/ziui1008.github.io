# 并格 2048

一款无需安装、无需构建、完全离线可玩的 2048 小游戏。

## 开始游戏

直接双击 `index.html`，使用现代浏览器打开即可。游戏不会请求任何网络资源。

- 键盘：方向键或 `WASD`
- 触屏：在棋盘上向四个方向滑动
- 撤销：恢复上一步棋盘、分数与随机状态
- 回放：使用右侧“回响记录”逐步查看本局过程
- 音效：可在顶部选择“哈基米”或“大狗”，每次游戏动作随机播放包内音效

## 游戏模式

- **经典**：标准 4×4 规则，可在达到 2048 后继续游戏。
- **今日挑战**：每天使用固定种子；同一天采用相同操作序列时，棋局结果一致。

## 本地数据

当前棋盘、最佳成绩、主题和声音设置保存在浏览器的 `localStorage` 中。浏览器禁止本地存储时，游戏仍能运行，但关闭页面后无法恢复进度。

## 开发验证

无需安装依赖。已安装 Node.js 时可运行：

```powershell
npm start
npm test
npm run check
```
