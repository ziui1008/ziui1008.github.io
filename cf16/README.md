# 蹭饭大富翁 · 毕业旅行

一款依据班级大学录取去向制作的本地多人棋盘游戏。支持 2～6 人在同一台手机、平板或电脑上轮流游玩。

## 直接运行

双击 `index.html` 即可游玩。这个模式不需要安装依赖，也不需要网络或服务器。

如果需要安装为 PWA 或验证离线缓存，请在本目录启动任意静态文件服务器，例如：

```powershell
npx serve .
```

然后在浏览器中打开显示的本地地址。PWA 的 Service Worker 只能在 `http://localhost` 或 HTTPS 环境注册，这是浏览器本身的安全限制，不影响双击运行游戏。

## 游戏内容

- 60 位同学、41 所大学与 22 个城市目的地
- 30 格全国旅行棋盘；城市落点优先安排尚未拜访的同学接站
- 2～6 人本地轮流
- 饭票、车票、友谊值和省份印章
- 旅途事件、高中回忆和个人目标
- 8、10、12 轮三种时长
- 自动保存在当前浏览器
- 隐私模式与本地离线运行
- 新开局规则说明与随时可查的帮助页
- 桌面端 16:9 横向棋盘，按窗口高度自动适配

## 测试

项目只使用浏览器原生能力。安装 Node.js 后可运行：

```powershell
node --test tests/engine.test.js
```

`tests/e2e.cjs` 是可选的浏览器端到端验收脚本，需要本机提供 Playwright；它覆盖开局、掷骰、存档恢复、手机布局、图鉴弹窗与离线重载。

## 隐私

同学姓名仅保存在 `data.js` 中，不会上传或发送。若把项目发布到公开静态网站，任何访问者都可能下载网页内的数据；公开发布前应取得相关同学同意，或默认启用隐私模式。
