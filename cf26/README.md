# 蹭饭大富翁 · 326班毕业旅行

一款依据326班大学录取去向制作的本地多人棋盘游戏，支持 2～6 人在同一台手机、平板或电脑上轮流游玩。

## 直接运行

双击 `index.html` 即可游玩，不需要安装依赖、网络或服务器。

如需安装为 PWA 或验证离线缓存，可在本目录启动静态文件服务器：

```powershell
npx serve .
```

## 游戏内容

- 17 位同学与 16 所大学，每位同学拥有独立大学落点
- 30 格全国旅行棋盘
- 2～6 人本地轮流
- 饭票、车票、友谊值和省份印章
- 差异化大学接站文案与地区视觉主题
- 旅途事件、高中回忆和个人目标
- 8、10、12 轮三种时长
- 自动存档、隐私模式和离线运行
- 新开局规则说明与随时可查的帮助页
- 桌面端 16:9 横向棋盘，按窗口高度自动适配

## 测试

```powershell
node --test tests/engine.test.js
```

`tests/e2e.cjs` 是可选的浏览器端到端验收脚本，覆盖开局、掷骰、接站弹窗、存档恢复、手机布局、图鉴与离线重载。

## 隐私

同学姓名仅保存在 `data.js` 中，不会上传或发送。若公开发布网页，应先取得相关同学同意，或默认启用隐私模式。
